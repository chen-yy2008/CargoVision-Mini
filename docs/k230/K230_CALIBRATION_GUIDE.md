# CargoVision K230 v1 现场标定指南

> 本指南归档 K230 v1 的现场标定方案。K230 板端源码目前位于独立本地工作区 `CargoVision_K230`，尚未同步到本仓库；文中的板端源码路径均指该本地工作区。

## 1. 标定原理与当前状态

- **已实现。** PC 端四点工具用实测矩形宽高和 TL → TR → BR → BL 四个像素角点求单应矩阵 `H`。K230 的 `workplane.project()` 将有效区域内的轮廓像素质心经 `H` 投影并做透视除法，得到 `center_mm`。局部原点为 TL，+X 沿 TL → TR，+Y 沿 TL → BL。板端 v1 仅接受匹配分辨率的 `raw` 标定。对应 K230 本地文件：`board/workplane.py`。
- **理论方案。** 在参考位置标定一次。相机沿同一目标平面平移时，同一像素对应的平面点跟随相机平移。把 `H` 的输出作为随相机移动的局部毫米坐标，再用龙门架位移换算到机械绝对坐标。
- **待现场验证。** 当前板端配置 `workplane_file` 为空，对应本地文件 `board/settings.json`；尚无实际加载的工作平面标定，实时结果的 `mm_status=uncalibrated`。UART v1 返回像素诊断。机械绝对坐标转换尚未实现。曝光帧与机械位置的对应关系、全行程误差均待现场验证。

## 2. 核心坐标公式

```text
P_target = P_TL_ref + Q × P_local + (P_gantry - P_gantry_ref)
```

| 参数 | 含义与参考坐标系 |
| --- | --- |
| `P_target` | 目标在机械坐标系中的绝对 XY，mm。 |
| `P_TL_ref` | 相机处于标定参考位置时，标定矩形 TL 在机械坐标系中的绝对 XY，mm。 |
| `P_local` | `H` 输出的 `center_mm`，以随相机移动的局部 TL 为原点，单位 mm。仅使用 `mm_status=valid` 的结果。 |
| `Q` | 局部 XY 方向到机械 XY 方向的 2×2 无量纲正交矩阵。由实测确定旋转、轴交换和正负方向。 |
| `P_gantry` | 实际曝光帧对应的龙门架机械 XY，mm。 |
| `P_gantry_ref` | 拍摄标定图像时的龙门架机械 XY，mm。与 `P_gantry` 使用同一机构参考点和坐标定义。 |

## 3. 标定前提

- 摄像头安装刚性可靠，沿目标平面平移时，相机相对该平面的高度和角度保持一致。
- 使用同一相机、镜头、焦距、采集分辨率和图像方向，标定图与检测帧使用同一 `raw` 像素空间。
- 明确被识别点所在平面。识别物体顶面时，标定板应位于对应高度。
- 机械位置须对应实际曝光。首轮采用停稳后 `CAPTURE`，保持位置至应答，并验证 UVC 缓冲中旧帧的处理方式。

## 4. 现场标定步骤

1. **确认机械基准。** 完成回零，标出原点和 X/Y 正方向。用量具核对上报毫米与实际位移。
2. **取得参考帧。** 让龙门架停稳，拍摄标定矩形，同时记录 STM32 的 `P_gantry_ref`。测量 TL 的机械绝对坐标 `P_TL_ref`，并记录相机安装、目标面高度和采集模式。
3. **生成四点标定。** 实测 TL→TR 和 TL→BL 的边长。在 Windows 对照项目中用现有 `calibrate_plane.py` 对 K230 原始样张按顺序点选四角，生成并记录 `raw` 标定及其 ID。
4. **确定 `Q`。** 测量 TL、TR、BL 的机械坐标，以 TL→TR、TL→BL 的单位方向分别作为 `Q` 的两列。核对两轴的正负、垂直度和实测尺度。出现明显不一致时排查量具、轴向和机械误差。
5. **跨位置验证。** 让同一个已知位置的固定点分别出现在不同龙门架停靠位置的有效视野内。记录每帧的机械 XY 和局部毫米坐标，代入公式，核对所得绝对 XY 的一致性。覆盖 X/Y 两轴和正反向接近。

## 5. 误差验收

用未参与四角标定和 `Q` 求取的独立测量点，覆盖视野中心、边缘和多个龙门架位置。每次记录点位 ID、真值 XY、预测 XY、龙门架 XY、接近方向、帧号和标定 ID。真值与预测均使用机械绝对坐标，单位 mm。

- 逐轴误差 `ΔX = X预测 − X真值`，`ΔY = Y预测 − Y真值`。
- 单点平面误差 `e = √(ΔX² + ΔY²)`，统计 `max(e)` 和 `RMSE = √mean(e²)`。独立点统计可复用 Windows 对照项目的 `scripts/evaluate_calibration.py`。
- 对同一点比较不同停靠位置和正反向接近时的预测散布，单独记录重复性。验收容差由团队确定，容差确认后再判定通过。

## 6. 现场检查清单

- [ ] 回零有效，机械原点、正方向及实际毫米位移已核对。
- [ ] 相机安装和采集模式已记录，标定板与目标识别点同高。
- [ ] 参考帧、`P_gantry_ref`、`P_TL_ref`、矩形实测尺寸和四点标定 ID 已记录。
- [ ] `Q` 的两轴方向已实测，停稳后的新帧已验证。
- [ ] 独立点已覆盖多个停靠位置和接近方向，误差与重复性报告已填写。

## 7. 待电控确认

- `CAPTURE` 中的机械 XY 代表哪个实体参考点，使用哪个原点和坐标系。
- X/Y 对应的运动方向、正方向、毫米换算、行程和有效范围。
- 回零完成及回零失效如何判断，复位或失步时如何标记位置无效。
- XY 位置来自编码器反馈、脉冲累计还是指令位置，有效性和更新时间如何提供。
- 如何表示已停稳、何时锁存上报的 XY，以及能否保持位置直到收到对应帧的应答。
