# K230 板端视觉端文档

本目录归档 CargoVision K230 v1 的板端通信、坐标标定和阶段状态。

> **仓库边界：** 当前仓库的主体仍是 Windows + Python + OpenCV 桌面版。K230 v1 的板端源码目前保存在独立的本地工作区 `CargoVision_K230`，本次只同步文档，没有把板端源码、测试脚本或 SD 卡镜像加入本仓库。因此，克隆本仓库并不能直接部署 K230 固件。

## 文档

- [阶段状态与下一步](K230_STAGE_STATUS.md)：硬件/固件环境、已完成工作、测试边界和待办。
- [UART 诊断通信说明](K230_UART_DIAGNOSTIC.md)：第一版诊断协议、引脚、回环测试步骤与限制。
- [现场标定指南](K230_CALIBRATION_GUIDE.md)：四点平面标定、相机随动坐标转换、现场测量与误差验收。

## 当前阶段结论

- K230 端 UART 诊断软件和离线测试已完成。
- CanMV IDE 4.0.9 与 USB REPL 已在实机验证。
- UART2 GPIO 物理回环、STM32 双向通信、机械绝对坐标转换和运动联调仍未完成。
- 当前诊断协议返回像素坐标 `PX`，不是机械毫米坐标，也不会触发电机运动。

本目录是阶段归档，不代表 K230 v1 已发布或整机验收通过。
