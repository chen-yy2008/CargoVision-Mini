### 1.3 A1 的现行数据约定与缺口

- 嵌套字段：`center_px`（浮点矩形中心）、`long_side_px`、`short_side_px`、`aspect_ratio`、`angle_deg`、`orientation_valid`、`corners_px`。中心/角点/边长均为 pixel，不是毫米。
- 图像 +X 向右、+Y 向下，正角顺时针；无向长轴为 `[-90°,90°)`，竖直为 -90°。四角按图像顺时针排列，从 `(y,x)` 字典序最小顶点开始，不是标定四角的 TL/TR/BR/BL 标签。
- `ORIENTATION_MIN_ASPECT_RATIO=1.10`；长宽比低于阈值时方向为 false、角度为 null。退化/非有限几何不附加字段，边界外的合法矩形角点不裁切。
- 外层 `center_px` 仍为轮廓矩质心，`center_mm` 仍由原质心映射。几何所属空间与 `pixel_frame` 的 raw/undistorted 一致。当前 JSON 仍为 schema 0.2。
- **A2 尚未实现**：`draw_detections()` / `render_workbench()` 仍是原边框、十字、编号和坐标列表，未显示新增旋转矩形或长轴。当前几何数据不等于形状分类、物理尺寸、机械角度或抓取点。
- **B/C 尚未实现**：现有工作平面坐标不是机械坐标；PNG/JSON 文件导出不是机器人通信协议，当前没有机械坐标转换或机器人通信实现。

### 1.4 已知问题与待验收事项

1. OV4689 的已验收基线为640×480；1280×720曾黑屏，重新插拔后640×480恢复，高分辨率不作为稳定模式。
2. 缺少精密固定装置和独立测量数据，没有定量毫米精度结论；相机移动、镜头、采集模式或平面改变后需重新验证/标定。
3. 启动器阶段用户说明 USB 未连接，要求暂不处理；该次打开失败不视为设备故障，也不视为启动器实机通过。恢复硬件测试前先确认设备可用。
4. HSV 受光照、反光、遮挡和目标粘连影响；长宽比阈值仅是方向有效性的简单门槛。ID 仅当前帧唯一，无跨帧跟踪；透视画面中的角度和长短边不能直接当成实物角度/毫米尺寸。

## 2. v0.4 总体目标与完成边界

将颜色识别与平面定位原型，分阶段推进为具备**目标几何分析、经验证的坐标转换、视觉数据接口与模拟通信**能力的比赛视觉系统。真实机械/电控接入以团队确认和实验室验收为前提，不因版本名称提前宣称可抓取或可比赛。

推进顺序：A1代码复核 → A2可视化 → A3真实物体功能验证；B先确认坐标约定，再开发及测量；C的软件模拟可并行，机械字段和实物联调须等待B及电控接口确定。原有定位字段、CLI、启动器及操作习惯作为兼容基线。

## 3. 详细开发路线

以下为待执行任务；“方案”是实现方向，不是新增功能完成声明。

### A1：目标几何信息提取

- **目标/功能**：保留现有颜色、质心、面积与毫米定位，提供上文七项旋转矩形信息。
- **方案**：复用 `vision.py:rotated_rect_geometry()`，沿用已实现的长轴角、角点和1.10门槛，不重写检测器。
- **依赖**：本分支 A1 提交、固定依赖和合成样本；实测另需 USB 及真实目标。
- **验收标准**：水平/旋转矩形、圆/近方形、阈值边界、角点顺序、退化输入、旧质心与毫米值、有限JSON及旧对象导出测试保持通过；实物表现归A3验证。
- **交付成果**：已有源码、15项几何测试、字段说明与回归记录；补充A3证据后才能标记几何实测完成。
- **状态**：代码已完成；待实测。不能把整个v0.4标为完成。

### A2：几何信息可视化展示

- **目标/功能**：在原 OpenCV 工作台展示旋转矩形、矩形中心、可靠长轴及角度/长短边/长宽比；区分原轮廓质心。方向无效显示“--/无有效方向”，不画误导性方向箭头。
- **方案**：优先扩展现有 `display.py` 和 `vision.py:annotate_frame()`，复用分页/详细模式，避免密集文字重叠。只将显示副本坐标缩放，显示边界裁剪不得回写角点；PNG仍使用原采集尺寸，JSON保持原始数值。
- **依赖**：A1字段稳定；确认新增显示内容和开关，不引入新GUI框架或改写启动器。
- **验收标准**：合成目标的框/轴与已知几何对应；不同窗口比例、Mask、边界目标和多目标分页正常；不改变检测数量、旧坐标、JSON或P/S/Q/Esc。缺geometry的旧对象仍能显示；人工窗口检查与自动化测试分别记录。
- **交付成果**：显示改动、显示几何回归测试、示例截图及使用说明。
- **状态**：未开始。先完成最小可读显示，不制作复杂美术。

### A3：真实物体几何识别测试

- **目标/功能**：验证真实画面下几何提取与方向门槛的可用性，记录偏差、抖动和失败条件；本阶段不增加自动形状分类器。
- **方案**：先用640×480固定台面，至少测试长矩形、近方形、圆形三类，每类3处位置；长矩形增加0/30/60/90°示例摆放条件，每条件连续记录10帧。手工标注物体类型，保存原始条件和JSON；不因失败挑帧隐藏结果。
- **依赖**：USB连接、测试物、照明及相机固定；精度统计另需稳定支架、可靠量具和独立验证点。物体最终尺寸/材质规格待团队确认，上述对象仅为测试样本。
- **验收标准**：完成可复现记录，核对提取数量、中心/框、方向有效性、图像角度与重复性；图像角度真值应由同一图像中的参考边确定，不能把斜视下实物摆角直接当真值。毫米点误差复用现有统计工具；四个拟合角点的误差不能当作独立精度。精度容差未确认前只报告数值，不判定“达到比赛精度”。
- **交付成果**：条件清单、样本索引、逐帧结果与失败案例、统计报告和可接受场景范围；真实照片/标定默认留本机，公开样本须另行确认。
- **状态**：专项测试未开始；A1实测待补充；实验室定量精度待外部条件确认。

### B：工作平面坐标到机械坐标转换

- **目标/功能**：把有效 `center_mm` 转为有明确原点、轴向和单位的机械平面坐标；保留原工作平面坐标及其来源，不直接控制电机。
- **方案**：先形成双方坐标约定和测量流程，再用小函数与显式参数实现。单位统一、轴正交且无需缩放时优先考虑二维刚体变换；轴交换/镜像须来自明确轴定义，不用任意缩放掩盖误差。变换参数通过实测对应点确定，另用未参与求参的点验证。配置应包含坐标系、单位、适用条件与标识；模型最终由团队确认。
- **依赖**：机械原点/轴方向/行程与可重复回零、相机固定、测量基准；抓取点是否等于当前质心须先讨论。条件不足时只用明确标为模拟的参数，不生成真实可执行机械目标。
- **验收标准**：离线已知平移/旋转及约定轴向样本正确；无标定、ROI外、非有限、超出已确认边界或参数失配时明确拒绝有效机械输出，不填零伪装成功。实验室独立点满足团队预先确认的容差后，才可标记机械坐标实测合格。
- **交付成果**：坐标约定/示意图、转换函数与配置、离线测试、对应点及独立验证报告；新增字段位置/版本在实施前确定，不覆盖 `center_mm`。
- **状态**：待外部条件确认，代码未开始。A1的pixel边长和角度不自动升级为机械长度/角度；若后续需要机械方向，另定义并验证转换。

### C：视觉数据接口及模拟通信

- **目标/功能**：提供可供接收端理解的视觉消息与本机模拟收发，验证无目标、无效定位及异常数据处理；不把接口测试当作机器人联调。
- **方案**：先约定字段、单位、坐标系和状态，优先用普通字典、序列化/解析函数及一个模拟接收端；内存或本机回环择一即可，不建设插件框架。保留现有0.2结果导出，新增消息封装/版本单独约定。消息序号与每帧目标id分开；多目标选择规则、时间有效性及失败状态显式表达。
- **依赖**：C的软件模拟可先行；机械字段依赖B。电控板、物理接口、帧格式、速率、校验/应答/重发、超时和停机语义均待讨论，不预设串口参数。
- **验收标准**：模拟收发一致；空目标、多个目标、方向null、无效/过期坐标、损坏/截断或非法数值消息均有约定行为，不误转成有效抓取目标；模拟断开/恢复可复现。真实传输层及执行响应只能在协议确定后另行联调验收。
- **交付成果**：标为草案的接口文档、消息示例、序列化/解析及模拟接收代码、异常测试记录；真实硬件协议作为后续确认成果，不标为本阶段已实现。
- **状态**：软件模拟未开始；真实电控接入待外部条件确认。

## 5. 测试与验收规范

| 层级 | 执行与证据 | 能够得出的结论 |
| --- | --- | --- |
| 自动化测试 | `python -m unittest discover -s tests -q`；记录提交、环境、通过/失败/跳过数；新增功能加对应测试 | 软件逻辑与兼容性，不证明真实图像、相机或毫米精度 |
| 桌面模拟 | 合成图/已有样图、窗口操作、模拟坐标与模拟消息；记录输入、预期、实际结果 | 展示/操作/数据链可复现；模拟机械参数不是实验室参数 |
| 真实摄像头测试 | 核对物理设备画面、实际分辨率/后端、光照、模式、安装及标定；记录持续运行表现和异常 | 该设备条件下的功能/稳定性；不凭FPS或输出毫米数字推断精度 |
| 实验室精度测试 | 固定装置、独立量具和验证点，记录真值/预测值、逐点dx/dy/距离、均值/最大值/RMSE及重复性 | 仅对测过的安装、工作平面和范围有效；须与预先确认的容差比较 |

每阶段用同一提交留存输入、步骤、结果、限制及负责人确认。缺设备/量具须写“待实测”，失败不得计作通过；不将跳过项算成硬件验收。角度误差须考虑无向长轴的180°等价；像素误差、毫米误差、消息延迟分别统计。不能把外接矩形pixel边长当真实物体毫米尺寸。

## 8. 风险、阶段门槛与后续规划

- **成像与几何**：光照/反光/粘连会改变轮廓；近方形方向易跳变，像素量化和透视会影响边长/角度。先记录失败条件并约束工作范围，再讨论算法调整。
- **标定与坐标**：平面高度、镜头/相机位姿变化会使映射失效；高物体顶面不能按桌面同一平面解释。原点/轴向或抓取点不明确时停止真实机械坐标交付。
- **数据与接口**：当前id不是跟踪id；失效、空目标、超时等状态不能误作零坐标。模拟字段不能被误认为已经与某电控板兼容。
- **版本与范围**：下一步先做A2和可独立完成的软件测试，再补A3；B/C按外部条件解锁。每阶段独立提交、附验证记录；合并及正式版本发布另行授权，不因本任务书存在而自动发布。
- **后续技术选择**：当前优先传统OpenCV、固定相机和平面方案；只有实际目标或测量证据表明现有路线不足时，才单独评估YOLO、ROS2、三维视觉等方案，不提前引入新依赖或通信控制功能。
